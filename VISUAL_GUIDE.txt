┌─────────────────────────────────────────────────────────────────────────────┐
│                      📊 DATABASE SCHEMA                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    job_templates
    ┌────────────────────────────────────────┐
    │ id (Primary Key)                       │
    │ name (VARCHAR)                         │
    │ client_id (FK → clients.id)            │
    │ pickup_address_id                      │
    │ pickup_time_begin                      │
    │ pickup_time_end                        │
    │ template_data (JSON)                   │
    │   {                                    │
    │     "pickup": {...},                   │
    │     "dropoffs": [...],                 │
    │     "return": {...}                    │
    │   }                                    │
    │ created_at, updated_at                 │
    └────────────────────────────────────────┘
              ↓ has many
    
    jobs
    ┌────────────────────────────────────────┐
    │ id (Primary Key)                       │
    │ job_template_id (FK)                   │
    │ date                                   │
    │ ... (other job fields)                 │
    └────────────────────────────────────────┘

    locked_fields
    ┌────────────────────────────────────────┐
    │ id (Primary Key)                       │
    │ field_name (e.g., "pickup")            │
    │ is_locked (BOOLEAN)                    │
    │ model (e.g., "job_template")           │
    │ model_id (which template/job)          │
    └────────────────────────────────────────┘
